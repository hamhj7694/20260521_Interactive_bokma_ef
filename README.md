**체험 사이트(공개 배포 완료):** https://hamhj7694.github.io/20260521_Interactive_bokma_ef/

> **배포 확인:** GitHub Actions 빌드·배포가 성공했고, 배포 워크플로에서 공개 URL의 HTTP 응답과 체험 안내·카메라·초기화 버튼 요소를 확인했습니다. 실제 손 제스처 반응은 사용 중인 웹캠과 환경에서 추가 확인해 주세요.

권장 환경: **PC 크롬·엣지 / 웹캠 / HTTPS 연결**. 처음 접속할 때 브라우저의 **카메라 사용 권한을 허용**하세요. 카메라는 체험용이며 음성은 요청하지 않습니다.

### 🕹 손동작별 사용법

| 기술 | 손으로 하는 동작 | 화면에서 나타나는 효과 |
| --- | --- | --- |
| **복마어주자** | **한 손의 검지·중지는 위로 펴고, 약지·새끼손가락은 접은 모습**을 카메라에 보이며 약 **3초** 유지 | 충전 테두리 → 붉은 안개·문 연출 → 화면 분할·균열 → 장면 전환 |
| **푸가** | **양손을 카메라에 보이고, 양쪽 손의 손가락을 살짝 구부린 자세**를 약 **2초** 유지 | 두 손 사이에 불꽃 구슬 생성 |
| **푸가 2단계** | 푸가가 시작된 다음 **양손을 좌우로 벌림** | 불꽃 구슬이 늘어나 **불기둥**으로 변함 |
| **푸가 3단계** | 양손을 충분히 벌려 불기둥이 최대 길이에 도달한 다음, **화면에서 왼쪽으로 보이는 손의 검지·중지 방향을 움직임** | 손가락 위치·방향에 따라 불기둥의 위치와 각도 제어 |
| **초기화** | 키보드 **R** 또는 화면의 **‘↻ 초기화 (R)’ 버튼** 클릭 | 효과·진행 상태를 초기화하고 다시 체험 |

**체험 순서**

1. 브라우저에서 카메라 접근을 허용하고 상반신과 손이 잘 보이는 곳에 서세요.
2. **복마어주자**: 한 손으로 검지·중지만 세운 자세를 약 3초 유지합니다.
3. 연출이 끝난 뒤 **푸가**를 이어서 시도하거나, **R**을 눌러 초기화합니다.
4. **푸가**: 양손을 약간 구부리고 약 2초 유지한 후 두 손을 벌려 불기둥을 만듭니다.
5. 불기둥이 충분히 펼쳐지면 화면의 왼쪽 손 검지·중지로 조작해 봅니다.

**참고:** MediaPipe가 손을 인식하는 방향과 카메라 미러링 때문에 화면의 좌우가 실제 좌우와 다르게 느껴질 수 있습니다. 복마어주자는 한 손만으로도 실행할 수 있고, 푸가는 두 손 모두 화면 안에 보여야 합니다. 하나의 기술 연출 도중에는 다른 기술 입력이 제한될 수 있습니다.

### 📷 인식이 안 될 때

- 웹사이트의 카메라 권한이 **허용**되었는지 확인하고 새로고침하세요.
- 얼굴·손이 역광이 되지 않도록 밝은 공간에서 시도하세요.
- 손가락 끝과 손바닥 전체가 카메라 화면에 들어오도록 조정하세요.
- 손가락 모양을 순간적으로 바꾸지 말고 해당 유지 시간 동안 안정적으로 보여주세요.
- 모바일에서는 권한·화면 크기·성능 제약이 있을 수 있어 PC 브라우저를 권장합니다.
- 먼저 **R**로 초기화하고 다른 기술을 시도하세요.

## 💡 기획 의도

**“애니메이션 속 캐릭터의 기술을 내 손동작으로 직접 써볼 수 있다면?”** 이라는 아이디어에서 시작했습니다.

영상 시청이나 단순한 버튼 클릭을 넘어, 실제 웹캠으로 추적한 손가락 위치와 손 모양을 기술 발동·화면 연출에 연결하는 실험입니다. 기존 손 추적 모델의 출력을 활용해 **제스처 판별과 애니메이션 상태 전환을 구현하는 브라우저 인터랙션**에 초점을 맞췄습니다.

## 🛠️ 어떻게 동작하나요?

```text
웹캠 입력 (브라우저)
      ↓
MediaPipe Hands — 양손 21개 관절 랜드마크
      ↓
손가락 펼침/굽힘 및 양손 위치·거리 계산
      ↓
제스처 감지 + 3초/2초 유지 판정
      ↓
기술별 상태 전환 (NORMAL / BOKMA / PUGA / FINAL)
      ↓
HTML Canvas — 장면·불꽃·균열·문 효과 렌더링
```

| 기술 | 역할 |
| --- | --- |
| JavaScript · Vite | 브라우저 인터랙션 애플리케이션 구성 |
| MediaPipe Hands | 기존 학습된 모델로 손 관절 위치 추정(최대 양손) |
| HTML Canvas 2D | 웹캠 합성과 그래픽·애니메이션 표현 |
| `getUserMedia` | 사용자가 허용한 카메라 영상 접근 |
| `requestAnimationFrame` | 연속 장면 렌더링 |
| 제스처 규칙 · 상태 관리 | 손 모양·움직임을 기술 발동과 장면 전환에 연결 |

**정확한 구현 범위:** 이 저장소는 객체 탐지·전신 자세 추정 모델을 직접 훈련한 프로젝트가 아닙니다. 이미 제공되는 MediaPipe 손 추정 결과에 규칙과 상호작용 로직을 적용한 **컴퓨터 비전 응용·AI 보조 코딩 프로토타입**입니다. 인물 분리(Selfie Segmentation) 시도 코드가 있지만 현재 기본 실행 경로에서는 비활성화되어 있습니다.

## 🧑‍💻 개발 과정

- 애니메이션 기술별 손동작·발동 조건 및 시각적 사용자 경험 정의
- AI 코딩 도구를 활용한 자바스크립트 화면·상태·제스처 처리 코드 구현·반복 수정
- 손 인식이 순간적으로 끊길 때 충전 상태가 불안정해지는 상황을 고려해 시간·프레임 기준으로 발동 조건 관리
- 손의 거리와 손가락 방향에 따라 효과의 크기·각도·위치를 조절하는 상호작용 구현
- 브라우저 카메라 이용을 위해 GitHub Pages의 HTTPS 배포 및 체험 가이드 구성

코드 작성에 AI의 도움을 받은 **바이브코딩 기반 개인 실험**이며, 자체 컴퓨터 비전 모델 학습이나 상용 수준의 인식률 검증 성과로 소개하지 않습니다.

## 💻 로컬에서 실행하기

Node.js **22 이상(22.12 이상 권장)** 과 웹캠이 필요합니다.

```bash
git clone https://github.com/hamhj7694/20260521_Interactive_bokma_ef.git
cd 20260521_Interactive_bokma_ef/domain-ar-mvp
npm ci
npm run dev
```

터미널에 표시된 로컬 주소(일반적으로 `http://localhost:5173/`)로 접속해 카메라를 허용하세요. `localhost`는 브라우저에서 카메라 사용을 허용하는 보안 컨텍스트로 처리됩니다.

```bash
npm run build
npm run preview
```

GitHub Pages 배포 파일은 `domain-ar-mvp/dist/`에 생성됩니다.

## 🚀 GitHub Pages 배포 설정

1. GitHub에서 이 저장소를 엽니다.
2. **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정합니다.
3. `main`에 반영된 `.github/workflows/deploy-pages.yml`이 빌드·배포를 실행합니다. 필요하다면 **Actions** 탭에서 워크플로를 수동 실행할 수도 있습니다.
4. **Actions → Deploy interactive demo to GitHub Pages**의 성공 상태를 확인합니다.
5. 성공 후 배포 주소 https://hamhj7694.github.io/20260521_Interactive_bokma_ef/ 로 이동하여 카메라 권한과 양쪽 제스처를 확인합니다.

**중요:** 비공개 저장소의 Pages 지원 여부는 GitHub 요금제·설정에 따라 다릅니다. Pages 공개가 제한된다면 저장소 공개 전환 또는 별도의 공개 저장소 사용을 검토해야 합니다. 공개 전환 시 소스코드·이미지·기타 저장소 파일이 외부에 노출되므로 먼저 내용을 점검하세요.

- 소스코드상 **웹캠 영상은 브라우저에서 MediaPipe로 처리**되며, 별도 녹화·서버 업로드 기능은 구현하지 않았습니다. 최초 실행 시 MediaPipe 관련 라이브러리·모델 파일을 CDN에서 불러옵니다.

- **《주술회전》 및 관련 캐릭터·기술·시각 자산은 각 권리자에게 귀속됩니다.** 본 프로젝트는 학습·포트폴리오 목적으로 제작한 비공식 팬 프로젝트로 원작 측의 후원·승인을 의미하지 않습니다. 공개 배포 시 이미지 등 자산의 이용 권한을 별도로 확인하세요.
